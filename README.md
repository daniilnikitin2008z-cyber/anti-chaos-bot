# 🤖 Телеграм-бот Анти-Хаос — готовый бот для воронки

Бот полностью реализует твою воронку:
`Reels (коммент ХАОС) → Директ → ТГ-бот → Гайд → Аудит 25 вопросов → Персональный оффер → Оплата`

---

## Что умеет бот
- `/start` и `/start chaos` (диплинк из Инсты) — приветствие + 2 кнопки
- Кнопка `📄 Скачать гайд` — выдает текст гайда «Дамп мозга» + кнопку на аудит
- Кнопка `🔍 Пройти аудит` — 25 вопросов по очереди (5 блоков), кнопки 0/1/2, прогресс-бар
- Автоподсчет баллов (макс 50) и сегментация:
  - 0-15 → легкий → ведет на 4 900₽
  - 16-30 → хронический → ведет на 9 900₽ (хит)
  - 31-50 → тотальный → спец 7 900₽ на 24ч
- Кнопки оплаты — внешние (Boosty / Gumroad / Stripe) — открываются в браузере
- Команда `/audit` — перезапустить аудит
- Готов к ManyChat/ChatPlace — диплинк `t.me/твой_бот?start=chaos`

## Установка за 10 минут

### Шаг 1: Создай бота
1. Открой Telegram → найди `@BotFather`
2. Отправь `/newbot` → придумай имя: `Анти-Хаос Бот` → юзернейм: `anti_chaos_xxx_bot` (должен кончаться на bot)
3. Скопируй токен вида `123456:AAH...`

### Шаг 2: Настрой ссылки
1. Создай 2 товара на Boosty / Tribute / Gumroad:
   - Товар 1: «Система Анти-Хаос База — 4 900₽»
   - Товар 2: «Система с разбором — 9 900₽»
   - (опционально) Товар 3: «Спец 7 900₽» — дубликат товара 2 со скидкой
2. Скопируй ссылки на них

### Шаг 3: Запусти бота

**Вариант A: Локально (для теста)**
```bash
cd telegram-bot
pip install -r requirements.txt
cp .env.example .env
# Открой .env в блокноте и вставь токен и ссылки
nano .env
python bot.py
```
Бот запустится и будет отвечать.

**Вариант B: На сервере 24/7 (Render.com — бесплатно)**
1. Залей папку `telegram-bot` на GitHub
2. Зайди на render.com → New → Background Worker → подключи репозиторий
3. Build Command: `pip install -r requirements.txt`
4. Start Command: `python bot.py`
5. Environment → Add: `BOT_TOKEN`, `PAYMENT_BASE`, `PAYMENT_PRO`, `PAYMENT_SALE`, `CONTACT_USERNAME`
6. Deploy → бот онлайн навсегда

**Вариант C: Railway / VPS / Timeweb**
То же самое, команда `python bot.py` — бот работает пока открыт терминал. Для фона используй `pm2` или `systemd`.

### Шаг 4: Подключи Инсту
1. ManyChat / ChatPlace → Триггер «Комментарий содержит ХАОС»
2. Авто-ответ в Директ: 
```
Вижу твой ХАОС 🔥 Лови гайд в ТГ (там удобнее):
👉 t.me/твой_бот?start=chaos
Жми Старт — заберешь за 30 сек
```
3. Готово!

## Где редактировать тексты и цены?

Открой `bot.py` → вверху блок `КОНФИГ`:
```python
PAYMENT_BASE = "https://..." # поменяй
PAYMENT_PRO  = "https://..."
CONTACT_USERNAME = "@your_username"
```

Вопросы аудита — в массиве `QUESTIONS` (можешь переформулировать).

Логику результатов — в функции `get_result()`.
